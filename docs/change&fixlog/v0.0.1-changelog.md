# v0.0.1-changelog

**版本**: v0.0.1  
**日期**: 2026-07-30  
**代号**: 项目初始化 & 框架搭建

---

## 概述

ValenceWinUI 项目的首个版本，基于 WinUI 3 + .NET 8 构建了完整的应用框架，包含导航系统、主题支持和首页图表可视化。

---

## 新增功能

### 项目基础架构
- 使用 WinUI 3（Microsoft.WindowsAppSDK 2.3.1）+ .NET 8 构建
- 支持 Packaged（MSIX）/ Unpackaged 双配置运行
- 支持 x86 / x64 / ARM64 多平台构建

### 应用框架
- **`MainWindow`**: 自定义标题栏 + NavigationView 侧边导航
- **导航系统**: `Frame` + `NavigationCacheMode` 页面缓存，支持入场动画和返回导航
- **页面结构**: Page1 ~ Page4 + Settings 五个页面
- **设置页**: 支持 Light / Dark / System 三种主题切换

### UI 组件
- 自定义标题栏（`TitleBar`），集成 Mica 背景材质
- 响应式侧边导航栏，支持折叠/展开
- 窗口最小尺寸限制（640×500）

### 首页图表支持
- 集成 **LiveCharts2**（`LiveChartsCore.SkiaSharpView.WinUI 2.0.4`）折线图
- 5 种预设药物浓度方案，支持方案搜索与切换
- X 轴时间标签（HH:mm 格式），Y 轴浓度标注
- 右侧药物特征参数面板（Cmax、Tmax、AUC、t½）
- 图表支持 X 轴缩放

### 工具类
- `ThemeHelper`: 主题管理（Light / Dark / System）
- `TitleBarHelper`: 标题栏按钮主题适配
- `WindowHelper`: 窗口管理（尺寸限制、窗口跟踪）
