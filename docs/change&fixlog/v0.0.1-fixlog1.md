# v0.0.1-fixlog1 — LiveCharts2 图表无法渲染修复

**日期**: 2026-07-30  
**严重级别**: 高（功能完全不可用）  
**影响范围**: `Pages/Page1Page.xaml`、`Pages/Page1Page.xaml.cs`、`App.xaml.cs`

---

## 问题描述

首页（Page1Page）中集成的 LiveCharts2 折线图完全空白，不显示任何曲线、轴标签或图例。即使使用与官方 demo 完全一致的 XAML 硬编码数据，图表仍无法渲染。

---

## 根因分析

通过对比正常工作的官方 demo（`C:\Users\Mizauka\Desktop\live chart demo`）与项目代码，并结合逐步断点调试，定位到三个共同导致渲染失败的根因：

### 根因 1：`LiveCharts.Configure()` 与 WinUI 默认渲染冲突

- **位置**: `App.xaml.cs` 第 33–36 行
- **原因**: `LiveCharts.Configure(c => c.AddSkiaSharp().AddDefaultMappers().AddDefaultTheme())` 在 WinUI 平台上会覆盖 NuGet 包内置的 SkiaSharp 渲染管道默认配置，导致图表引擎内部 series 注册失败
- **证据**: 
  - 正常工作的官方 demo **完全没有** `LiveCharts.Configure()` 调用
  - 移除该调用后，硬编码测试数据可正常渲染
  - 运行时 `SeriesId` 始终为 `-1`（未被引擎注册），移除调用后恢复正常

### 根因 2：代码后台赋值 `XamlLineSeries.Values` 不触发图表更新

- **位置**: `Pages/Page1Page.xaml.cs` 中 `ApplyScheme()` 方法的 `allSeries[i].Values = pts`
- **原因**: XAML 声明的 `XamlLineSeries`（泛型 `object`）通过代码后台直接赋值 `ObservableCollection<DateTimePoint>` 时，其 setter 不会正确通知图表引擎刷新渲染。必须在图表初始化前通过 XAML 标记扩展（`{lvc:Values}`）设置，或在代码中创建强类型 `LineSeries<DateTimePoint>` 后整体替换 `DrugChart.Series`
- **证据**: 将 XAML `XamlLineSeries` 替换为纯代码 `new LineSeries<DateTimePoint>` 后赋值 `DrugChart.Series`，图表正常渲染

### 根因 3：X 轴 `MinStep` 参数导致渲染崩溃

- **位置**: `Pages/Page1Page.xaml.cs` 中 X 轴配置 `MinStep = TimeSpan.FromHours(1).Ticks`
- **原因**: `MinStep` 与 `DateTimePoint` 类型数据在 LiveCharts2 WinUI 后端存在兼容性 bug，设置后渲染管线静默崩溃
- **证据**: 单独移除 `MinStep` 保留 `UnitWidth` 后图表正常渲染；单独添加 `MinStep` 后图表再次空白

## 修复内容

### 文件 1：`App.xaml.cs`

**变更**: 移除 `LiveCharts.Configure()` 调用

```diff
- LiveCharts.Configure(c => c
-     .AddSkiaSharp()
-     .AddDefaultMappers()
-     .AddDefaultTheme());
```

### 文件 2：`Pages/Page1Page.xaml`

**变更**: 移除 XAML 中声明的空 `XamlLineSeries`，`CartesianChart` 不再包含预设子元素

```diff
- <lvc:CartesianChart.Series>
-     <lvc:SeriesCollection>
-         <lvc:XamlLineSeries x:Name="SeriesA" />
-         <lvc:XamlLineSeries x:Name="SeriesB" />
-         <lvc:XamlLineSeries x:Name="SeriesC" />
-     </lvc:SeriesCollection>
- </lvc:CartesianChart.Series>
```

### 文件 3：`Pages/Page1Page.xaml.cs`

**变更**: 
- 用纯代码创建强类型 `LineSeries<DateTimePoint>`，通过 `DrugChart.Series = new SeriesCollection { ... }` 赋值
- X 轴移除 `MinStep` 参数，仅保留 `Labeler` 和 `UnitWidth`

```diff
- var allSeries = new[] { SeriesA, SeriesB, SeriesC };
- allSeries[i].Values = pts;
- allSeries[i].SeriesName = scheme.Drugs[i];
- // ... 逐一设置属性
+ var newSeries = new SeriesCollection();
+ newSeries.Add(new LineSeries<DateTimePoint>
+ {
+     Values = pts,
+     Name = scheme.Drugs[i],
+     // ... 对象初始化器
+ });
+ DrugChart.Series = newSeries;
```

```diff
  new Axis
  {
	  Labeler = v => new DateTime((long)v).ToString("HH:mm"),
	  UnitWidth = TimeSpan.FromHours(1).Ticks,
-     MinStep = TimeSpan.FromHours(1).Ticks,
  }
```
